This is a sample post. Any Markdown file you drop into `src/content/blog/` shows up here automatically.

## How to publish an essay

1. Create a new `.md` file in `src/content/blog/`, for example `my-essay.md`.
2. Add the header block at the top (title, description, date, tags).
3. Write the essay below it in plain Markdown.
4. Commit and push. The site rebuilds and deploys on its own.

> Set `draft: true` in the header to keep a post off the live site while you work on it.

Long essays will get a dedicated reading layout in a later step: table of contents, reading progress, and estimated reading time.
